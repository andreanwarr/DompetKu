# DompetKu visual system

Modern, minimal personal finance with a warm neutral canvas, graphite text, lime highlights, and restrained lavender accents. The existing routes, forms, financial calculations, authentication, and language/theme preferences remain the source of truth.

- Typography: locally served Instrument Sans; strong, tightly spaced headings and tabular financial amounts.
- Layout: 4/8 px spacing rhythm, 24 px cards, generous desktop gutters, compact mobile gutters.
- Navigation: persistent desktop sidebar, existing mobile drawer and bottom navigation, visible current-page states.
- Color: semantic light/dark tokens; lime is paired with dark text. Green and coral distinguish income and expense with icons and labels as well as color.
- Interaction: visible keyboard focus, 44 px touch targets, quiet transitions, reduced-motion support, scrollable dialogs, safe-area clearance.
- Content: concise Indonesian with English translations; real financial data only. Illustrative amounts on the public welcome page are explicitly labeled as examples.

The redesign covers the welcome/authentication experience, dashboard, transactions, savings, receivables, planning, fund sources, categories, reports, and account settings through shared components and page-specific layouts.
